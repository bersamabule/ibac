## Overview

This knowledge base configures an AI system to function as an expert IB MYP Language and Literature assessor. It contains:

- **Diagnostic frameworks** for each of the four assessment criteria
- **Student archetypes** for pattern recognition
- **Calibrated case studies** with worked examples
- **Assessment protocols** for fair, consistent evaluation
- **Compensation rules** governing cross-criteria interactions

## How to Use This Knowledge Base

### For Assessment
1. Load `00_SYSTEM_PROMPT.md` (always)
2. Load the criterion module(s) for criteria being assessed
3. Load `05_CROSS_CRITERIA/` modules for compensation rules
4. Load `06_ASSESSMENT_PROTOCOLS/AP1_two_pass_grading.md`

### For Comparison Reports
1. Load both assessments being compared
2. Load relevant criterion modules
3. Load `05_CROSS_CRITERIA/CC1_student_archetypes.md`

### For Knowledge Base Refinement
1. Add edge cases to `08_EDGE_CASES/` as discovered
2. Review batched (weekly/monthly)
3. Update relevant modules with new patterns
4. Version the changes

## Key Concepts Quick Reference

### The Four Criteria

| Criterion | Assesses | Key Question |
|-----------|----------|--------------|
| A - Analysing | Analytical thinking | How does this text create meaning? |
| B - Organizing | Structure and logic | Does the organization serve the argument? |
| C - Producing Text | Creativity and voice | Is there genuine creative engagement? |
| D - Using Language | Linguistic competence | Does language serve communication? |

### The Achievement Levels

| Level | Keywords | Typical Performance |
|-------|----------|---------------------|
| 1-2 | Limited, Minimal | Struggling (10-20%) |
| 3-4 | Adequate, Some | Majority (40-50%) |
| 5-6 | Substantial, Competent | Above average (25-35%) |
| 7-8 | Perceptive, Sophisticated | Exceptional (5-15%) |

### The Compensation Rules

1. **Structural Ceiling:** B limits A (chaos caps analysis)
2. **Linguistic Floor:** D supports A (weak language doesn't penalize clear thinking)
3. **Style ≠ Substance:** D/C ≠ A (beautiful writing doesn't equal deep thinking)

### The Student Archetypes

| Archetype | Profile | Limiting Factor |
|-----------|---------|-----------------|
| Unbound Architect | High A, Low B | Organization |
| Polished Hollow | High B/D, Low A | Thinking |
| Thinker in Translation | High A, Low D | Language |
| Checkbox Champion | Moderate all | Disposition |
| Risk-Averse Technician | High B/D, Low C | Courage |
| Intuitive Rambler | High C, Low B | Organization |
